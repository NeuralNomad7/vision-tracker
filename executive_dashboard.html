Technical Highlights

Production-hardened from the ground up

🎯

Kalman-Filtered Tracking

4-state filter (position + velocity) predicts object motion between frames, smoothing out noise and occlusions.

🔄

Graceful Degradation

Survives camera disconnects, serial port failures, and signal interrupts without data loss or crashes.

📡

ASCII Serial Protocol

Simple, human-readable protocol integrates with any microcontroller. No binary parsing, no dependencies.

📊

Millisecond CSV Logging

Full state capture at every frame — Kalman state, raw measurements, velocity, distance, bounding box.

🛡

Input Validation

All CLI inputs, file paths, and serial ports are validated against allowlists before use. No injection vectors.

⚡

Zero GPU Required

Pure CPU inference using classical CV. Runs on a Raspberry Pi, laptop, or any edge device with a camera.
